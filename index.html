Líneas (toca para mostrar/ocultar)
Datos de paradas: dataset abierto "Paradas de Vitrasa" del Concello de Vigo (datos.vigo.org), formato GeoJSON. Datos de líneas: feed GTFS de Vitrasa (datos.vigo.org); por cada línea se muestra un trazado representativo por sentido. El enlace de cada parada apunta al sistema de información en tiempo real de Vitrasa (infobus.vitrasa.es) usando el id numérico de cada parada del dataset.
